# 本地数据分析 Agent

在自己电脑上运行的网页，支持上传单个最大 1GB 的 CSV 或 XLSX 文件，预览数据，并用自然语言生成只读分析查询。网页只监听 `127.0.0.1:8000`。

## 主要功能

- **文件导入**：CSV / XLSX、8MiB 分片上传、暂停续传、工作表选择、取消导入和完整删除。
- **Excel 内容读取**：独立表格区域、常见合并表头、段落、文本框及浮动图片 OCR；提供来源位置与读取警告。
- **自然语言分析**：大模型生成 SQL，DuckDB 在本机计算，返回中文结论、表格和图表。
- **SQL 自动纠错**：对语法、字段、函数和类型错误进行有限次数修正，每次都重新检查只读和表权限。
- **数据看板**：生成指标与多图表，支持修改统计字段、分组、日期粒度、筛选和图形。
- **业务定义与历史**：字段说明、指标口径、数据质量概览、分析历史和连续追问。
- **账号与访问**：邮箱密码注册登录、用户数据隔离，以及可选的临时外网演示链接。

### 技术组成

| 部分 | 技术 |
| --- | --- |
| 后端接口与输入校验 | Python、FastAPI、Pydantic、Uvicorn |
| 本机计算与存储 | DuckDB、SQLite、JSON 元数据 |
| Excel 与图片读取 | openpyxl、RapidOCR |
| 模型调用与查询检查 | OpenAI Python SDK、DeepSeek / OpenAI、sqlglot |
| 网页界面 | HTML、CSS、JavaScript |
| 可选外网访问 | Cloudflare Quick Tunnel |

典型流程：上传文件 → 本机读取与校验 → 保存表结构和业务口径 → 模型生成 SQL → 只读检查 → DuckDB 执行（失败时有限纠错）→ 模型解释结果 → 保存历史或看板。

本项目借助 AI 辅助开发。运行时，大模型负责理解问题、生成查询和解释结果；具体数据计算由 DuckDB 完成。

## 启动

当前启动脚本针对 **Windows**，已在 **Python 3.12** 环境验证。首次下载项目后，在项目目录打开 PowerShell，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

在 `.env` 中填写自己的 API Key 和账号可用的模型名称，保存后启动：

```powershell
.\run.cmd
```

也可以在启动前通过 PowerShell 环境变量覆盖 `.env` 中的同名设置。如果使用 OpenAI，设置 `MODEL_PROVIDER=openai` 和 `OPENAI_API_KEY`；默认模型是 `gpt-4o-mini`，也可以用 `OPENAI_MODEL` 指定。

浏览器打开 <http://localhost:8000/>，点击“邮箱注册”，填写邮箱和至少 8 位密码。注册后可用该邮箱登录；不同账号只能访问各自上传的数据集和看板。若电脑开启了代理，`localhost` 通常比 `127.0.0.1` 更容易匹配本机绕过规则。如果不配置 API Key，登录后仍可上传、导入和预览文件，但无法使用自然语言提问。`.env` 包含密钥，请不要分享或提交该文件。

`run.cmd` 会在后台启动服务并打开网页，关闭启动窗口或浏览器不会停止服务；重复打开会复用已经运行的服务。电脑关机后服务会停止。要在每次登录 Windows 后自动启动，在项目目录运行一次：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup_startup.ps1
```

自动启动只对当前 Windows 用户生效，不需要管理员权限。登录电脑后稍等几秒，再打开 <http://localhost:8000/>；自动启动本身不会弹出浏览器。可以在 Windows“任务管理器 → 启动应用”中管理 `Local Data Analysis Agent`，或运行以下命令移除自动启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup_startup.ps1 -Remove
```

手动恢复时双击项目文件夹中的 `run.cmd`。启动失败的原因保存在 `data/startup-error.log`，服务错误保存在 `data/server-error.log`。如果移动项目文件夹，需要重新设置自动启动。关机期间网站无法访问，重新开机后文件、账号和历史记录仍然保留。

账号保存在被 Git 忽略的 `data/users.json`，其中保存的是加盐密码哈希，不是明文密码。登录状态使用浏览器 Cookie；重启服务后需要重新登录。邮箱目前只作为登录名，不会发送验证邮件，也没有邮件找回密码功能。

如果之前已创建旧版用户名账号，登录页会显示“旧账号绑定邮箱”：输入旧用户名、旧密码和要绑定的邮箱，原有数据会转入这个邮箱账号。如果旧版没有账号，首次注册的邮箱账号会接收原有未归属的数据。

## 使用

1. 选择 `.csv` 或 `.xlsx` 文件；CSV 可指定编码。点击“上传并导入”。
2. Excel 上传后勾选所有需要分析的工作表。CSV 会自动导入。Excel 同时支持规则表格、段落文字，以及常见的大标题、合并表头和嵌入图片文字。
3. 导入后查看“数据质量概览”：每列的类型、缺失比例、最小值、最大值及常见取值。旧数据集可以点击“生成概览”补充统计。
4. 在“字段含义与指标口径”中填写数据说明、字段含义及业务指标计算方式，点击“保存说明与口径”。例如说明金额单位、退款是否排除、日期口径；保存后用于后续问答和看板。修改后，旧看板会提示重新生成。
5. 点击“生成数据看板”自动生成指标、图表和简短洞察。点击“编辑看板”可以修改标题、图形（柱状/折线/面积/饼图）、顺序，以及增删指标卡和图表。勾选“重新选择统计方式”可选择分组、求和/平均/计数、日期粒度和筛选条件，保存时重新查询本机数据，不调用模型。无结果或配置错误时保留旧看板；多人同时修改时会检查版本。修改后的自动洞察会清空，避免引用旧数据。
6. 输入分析问题，查看结论、图表、查询结果和 SQL。结果自动保存到“提问历史”，可以回看并继续追问；下一次提问默认承接当前结果，点击“开始新问题”可清除上下文。追问最多使用最近 6 轮前文，并始终重新查询当前数据。单次结果最多显示和下载前 200 行。
7. 上传中可以“暂停上传”，重新选择同一文件后点击上传即可续传。导入中可以“取消导入”，完成清理后可重新导入；原文件会保留。左侧每个文件旁均有“删除”按钮，点击后在页面确认框中核对文件名并确认，删除后清理该数据集的原文件、数据库、历史、看板和临时文件。导入中的文件会先请求取消，任务结束后再删除；若仍在统计或有文件被占用，确认框显示原因，可稍后重试。删除其他文件不会切换正在查看的数据集。

### SQL 自动纠错

提问和生成看板时，如果模型查询发生语法、字段引用、函数或类型转换错误，会把原查询、错误类型、表结构和业务口径交给模型修正，再次通过只读及表权限检查后执行。每条查询最多修正一次，整份看板最多尝试修正两条查询；不重复修正仍失败或内容相同的查询。纠错返回格式不正确时直接停止，不额外请求模型。

成功后页面提示“已自动修正查询”，显示和保存最终执行的 SQL；分析历史的 `sql_repair`、看板的 `sql_repairs` 同时记录原查询、最终查询及修正原因。失败时不保存分析历史；看板仍可保留其他成功图表，整份看板无法生成时保留旧看板。超时、内存不足、文件访问失败，以及权限检查拒绝的查询不会触发纠错。可执行不代表统计口径一定正确，仍需核对筛选、关联和业务定义。手动编辑看板继续按表单确定性生成 SQL，不调用模型纠错。

质量概览由本机 DuckDB 计算，无需调用模型。缺失值包含 NULL 及仅有空格、制表符或换行的文本；缺失比例按全表行数计算，数值和日期范围也统计全表。常见取值和不同值数量仅统计前 10,000 行，不是随机抽样；长取值显示前 160 个字符并标注省略，不会合并原始取值的计数。统计限时 120 秒，超时或失败不影响已导入数据的使用，可点击“重新统计”。

上传采用 8 MB 分片。关闭网页后，重新选择同名同大小文件可继续尚未完成的上传；重启服务后会回退未提交完的分片。上传前会按文件大小的 3 倍加 256MiB 预检剩余磁盘空间，Excel 解压可能超出这个估计。文件及分析数据库保存在 `data/`，不会作为完整文件发送给模型。分析请求会发送表结构、行数、缺失比例、数值/日期范围、业务定义、每表前 3 行的有限样例（文字合计上限约 16,000 字符），并按问题在本机查找相关文字片段（约 12,000 字符上限、最多 12 张表、3 秒查询限时）；这些片段可能包括图片识别的文字。常见取值统计列表仍仅在本机页面展示。结果摘要阶段最多发送 200 行，文字约 48,000 字符上限；过长文字会取问题附近的片段并明确提示覆盖不完整。追问时发送最近 6 轮历史问题、SQL、简短回答及每轮前 10 行结果，每轮文字上限约 8,000 字符。

## Excel 文字与图片

读取准确性更新（2026-10-23）：同一工作表中以空白列分开的独立表格会分别导入，并显示原始区域；空行隔开的 Q1/Q2 等问题说明另存为文字记录，空白工作表跳过。关联分析需要按“地区”“编号”等真实字段连接，不能按原表的行位置拼接。

CSV 与 Excel 的文本、编号、原始日期字符串先保留原文；数值列经过整列验证后才转换，金额采用十进制定点类型，避免浮点累加误差。无法安全转换的长整数、高精度数值和混合文本列保留为文本。日期原文可用于按日/月/年分组，界面标记为“日期（原文）”。Excel 的日期仍读取底层日期值；百分比等显示格式不等同于底层数值，请结合原表核对。

- 规则表格保留文本字段，模型会结合实际样例理解名称、说明和备注；提问时再执行只读查询，避免仅凭列名猜测。
- 自动检查前 40 行，识别常见标题、最多 3 层合并表头。表格上方说明会单独保留；纵向合并的文本分类会向下补齐，数值不会重复填充。复杂版式依然需要核对预览。
- 段落型工作表不把第一句当作字段名，而是保存为“原始行号、原始位置、文字内容”，支持查找、归纳和问答。
- 浮动图片与绘图文本框中的文字进入“说明与图片文字”表，附工作表、锚定位置、来源和 OCR 置信度。OCR 使用本机 RapidOCR，不上传原图，不调用额外图片模型。每张表最多识别 100 张图，单图不超过 16MB、2000 万像素，单图限时 60 秒；超限、外链、空结果或识别失败会在页面提示，不影响已读取的正文。OCR 不保证手写字、低清截图、复杂图表或表格结构的准确性。
- WPS `DISPIMG`、新版 Excel 单元格内嵌图片等富数据尚未转换识别；检测到相关格式时会显示提示，可先在 Excel 中转换为浮动图片。外部链接图片不会下载。
- 旧版 Excel 或 CSV 数据集可点击“重新读取文件（保留原数据集）”，复制原文件并用新版导入；原数据集、历史记录和看板保留，新数据集需按新字段重新设置口径和生成看板。
- 可尝试提问：“总结售后政策”“找出备注中提到退款的记录”“图片中规定的退货期限是什么，并注明位置”。大文件和多图资料不会一次性全部发给模型；需要完整覆盖时请分工作表、主题逐步追问。

历史记录保存在 `data/history/` 下每个数据集独立的 SQLite 文件中，刷新页面或重启服务后仍然保留。原有文件和数据集不需要重新上传。

## 大文件实测

已在当前 Windows 电脑上通过真实本机 HTTP 上传测试（结果见 [benchmarks/latest.json](benchmarks/latest.json)，方法与限制见 [benchmarks/README.md](benchmarks/README.md)）：

| 文件 | 数据行数 | 上传 | 导入和质量统计 | 服务进程峰值内存 |
| --- | ---: | ---: | ---: | ---: |
| 1GiB 合成 CSV | 2,097,152 | 6.24 秒 | 11.58 秒 | 约 1.32GiB |
| 5.37MiB Excel | 100,000 | 0.06 秒 | 10.09 秒 | 约 140MiB |

CSV 数据具有重复性，且未进行真实 1GiB XLSX 压测。以上数据来自准确性更新前的导入流程，新版增加了整列类型校验，尚未重新测量 1GiB 导入耗时。以上数据不能推算所有文件的速度和资源占用。

## 外地访问（临时演示链接）

- 双击项目根目录 `start_public.cmd`，会先确保本机网站运行，再开启 Cloudflare Quick Tunnel，显示可分享的 HTTPS 地址。同一通道运行期间重复启动会复用原地址。
- 当前地址保存在 `data/public_url.txt`。访问者使用自己的邮箱注册/登录，仅能看到自己的数据。外网登录和本机登录各自独立。
- 电脑、网络、网站服务和外网通道需保持运行。关闭启动窗口不会关闭通道；电脑关机后外网也无法访问。重新开机后需要再次运行 `start_public.cmd`，不自动开启外网访问。
- 双击 `stop_public.cmd` 关闭此项目的外网通道，本机 `http://localhost:8000/` 仍可使用。
- 此链接用于临时演示，重启通道后域名会变化，也没有持续可用保证。固定域名和长期运行需要另行配置正式 Tunnel 或部署服务器。详见 [Cloudflare 官方说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。
- 外网工具从 Cloudflare 官方 GitHub 发布页下载到 `data/tools/`，按官方 SHA-256 校验；不要求 Cloudflare 账号、购买域名或修改路由器入站端口。网站仍监听本机地址，由通道转发访问。

## 当前范围

- 支持 `.csv` 和 `.xlsx`。旧版 `.xls` 暂不支持。
- Excel 公式使用文件中保存的计算结果，不在本机执行公式。没有可读取结果时按空值导入，并在页面列出公式数量、工作表和最多 12 个单元格位置；请先在 Excel 中重新计算并保存，再重新读取。
- Excel 中以文字保存的金额保留原文；通过整列数值校验后标为“数值（保留原文）”，支持看板求和、平均、最小/最大值和数值筛选。编号、前导零、超出安全精度及混杂文字的列不会自动按数值解释。
- 表格列宽使用完整区域扫描结果；后面才出现的列仍保留在原记录中。没有列名时自动命名为“列N”，并提示核对列含义。
- 文字检索优先返回用于匹配的字段，避免宽表的备注位于后面的列时被列数限制截掉。计算产生 NaN/Infinity 时返回空值并明确提示，不会将其当作零或导致结果页面报错。
- 以上导入改进用于第 4 版读取结果。已有数据集可点击“重新读取”生成新版副本，原文件、原看板和原提问历史仍保留。
- 导入任务一次处理一个文件。CSV 可用 UTF-8、GB18030/GBK、UTF-16；自动识别出错时重新上传并手动选编码。
- 1GB 是上传文件大小上限。大文件实际处理需要更多临时磁盘空间；具体速度取决于文件内容和电脑配置。
- 支持多个邮箱账号及各自的数据隔离，但仍只监听 `127.0.0.1`，不提供公网访问或邮件验证。
